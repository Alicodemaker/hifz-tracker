# Roast: Hifz Tracker (fstack-roast)

## Answers

- **Who needs it most:** me, doing hifz.
- **Status quo:** nothing, I track it in my head.
- **Evidence:** I need it myself.
- **Smallest useful version:** a daily log plus a plan for today.

## What is real

- The builder is the user and would use it daily.
- When nothing is tracked, manzil slips first: older juz fade without anyone noticing.

## What is wishful

- The status quo is "nothing", so the pain may not be strong enough to form a habit. Logging must take seconds.
- "Today's plan" can grow into a scheduler. Version 1 uses one simple, predictable rule.
- Other users (parents, teachers) are out of scope for now.

## The wedge

One PWA screen that shows today's sabaq, sabqi and manzil, with a big "done" tap for each and a simple history. Progress is counted in pages and manzil follows a fixed rotation. No stats, streaks, reminders or profiles.

**Verdict: Build the wedge.** Use it yourself for two weeks before adding anything.

> Terminology note: this roast predates ADR-0006. Sabaq, sabqi and manzil are now Hifz, Rabt and Muraja'a.
