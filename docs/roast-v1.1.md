# Roast: Quran page view, pace estimate, nav bar (fstack-roast, v1.1)

## Answers

- **Status quo:** another Quran app shows the page today.
- **Page job:** memorise and revise from it, so the text must be exact and trustworthy.
- **Pace:** "I'd adjust my amount", so it changes a real decision.
- **If only one ships:** the page view.

## What is real

- The builder uses the app daily and memorises from the page. Removing the switch to another app is the value.
- The pace estimate would change the daily amount.

## What is wishful

- A hafiz memorises the visual page (line starts, page ends). Text that just flows would break lines differently from the printed mushaf and teach the wrong page picture. Line-for-line fidelity needs trusted line-layout data and a matching Quranic font.
- The text must be exact, from a verified source, never hand-typed.

## The wedge

A read-only mushaf page (header with surah, page and juz; exact Uthmani text in the correct 15 lines; ayah markers; today's portion highlighted; swipe to adjacent pages) opened from the Hifz, Rabt and Muraja'a areas. Plus the pace line and the navigation bar fix. No search, audio, translation or bookmarks.

**Verdict: Build the wedge**, if exact line-layout data and a matching font can be bundled offline. Otherwise shrink to "open this page in your Quran app".
