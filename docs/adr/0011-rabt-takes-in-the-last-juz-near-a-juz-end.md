# Rabt takes in the last juz near a juz's end

ADR-0010 rotates the Rabt through the memorised surahs after the Hifz's surah that start in the Hifz's juz. Near the start of a juz (in memorisation order) that can be a single surah: with Hifz in Ghafir, only Fussilat starts in Juz 24 after it, so the Rabt was Fussilat every day for weeks and never seemed to move on. Now, when the current juz holds only one such surah or none, the surahs of the juz after it (the juz finished last) join the rotation: Fussilat to al-Jathiyah. They leave the Muraja'a while they're in the Rabt, as before. Only one more juz is taken, and only when needed, so the rotation stays short. The fallback for a rotation that is still empty (the surah memorised just before) is unchanged.

Logging a Day now moves progress on from the plan that Day showed, not from a plan worked out again, so a rule change like this one never skips a surah on the first day after an update.
