# The Mushaf page uses KFGQPC Unicode text and font, not page images or glyph fonts

The builder memorises from the page, so which words start and end each of the 15 lines must match the printed mushaf. The app bundles the KFGQPC Hafs Unicode text with its line breaks (npm `@quran.ws/text`, CC-BY-4.0), sets each line on its own and justifies it, using the unmodified KFGQPC HAFS Uthmanic Script font. It matches the 1441H print line for line on 601 of 604 pages; on pages 345 and 577 one word sits on a neighbouring line. We rejected the QCF glyph fonts (pixel-identical but about 38 MB, and not redistributable without KFGQPC's permission), page images (size and licence), and flowing text in a general Arabic font (it would teach the wrong page picture). The font must ship unmodified, with no subsetting, per its licence.
