# New memorisation follows surahs backwards, positioned by ayah

Sabaq moves through surahs from an-Nas towards al-Fatiha, each surah read from its first ayah to its last. That is how the builder actually memorises. Because one Juz 30 page holds several short surahs, "next page" has no meaning in this order, so the sabaq position is stored as surah + ayah. Pages remain the unit for sizes and amounts (ADR-0001). The app therefore needs ayah-to-page data, not only page data. We rejected "backward by juz, forward within the juz", which would have kept everything page-based but doesn't match how the builder memorises.
